FunnyBot 3000

A simple conversational chatbot built in Python that uses keyword recognition, random responses, and basic memory functionality to create an interactive terminal experience.

This project was created as a learning exercise to practice Python fundamentals including functions, dictionaries, loops, user input handling, and program logic.

⸻

Features

* Interactive command-line conversation
* Randomized responses for more natural conversations
* User name memory system
* Ability to recall stored information
* Keyword-based response detection
* Safe input handling
* Clean terminal interface

⸻

Technologies Used

* Python 3
* random - Selects random responses from response categories
* time - Adds delays to improve the conversation experience
* Dictionaries - Stores responses and user memory
* Functions - Organizes program logic into reusable sections

⸻

Example Conversation

================================
        FunnyBot 3000

How to Run

1. Make sure Python 3 is installed.
2. Clone the repository:

git clone https://github.com/Tjordanart/funnybot-3000.git

3. Navigate to the project folder:

cd funnybot-3000

4. Run the program:

python funnybot.py
